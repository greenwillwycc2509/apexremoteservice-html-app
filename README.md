## Frequently Asked Questions

**How can I view the project?**  
Open its main HTML file in a browser, or run the project directory through a local web server.

**How are site changes published?**  
Edit the HTML, CSS, JavaScript, and asset files used by the frontend, then redeploy the updated files.

Yes. Since the application is built with HTML, its structure and visual presentation can be changed in the source files.

**What should I check if the page is broken?**
